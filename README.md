**Wager960.** Co-founder and CTO. A skill based platform where players compete in chess,
standard and Chess960. Python, Django and Channels, with real time play over WebSockets. One

**[Making-A-LLM](https://github.com/abdus-a/Making-A-LLM).** A language model in pure Python.
No PyTorch, no NumPy, not even `str.split()`. MIT licensed, so fork it and take it apart.

I believe in humans driving AI, not the other way around. I treat it as software, in the same
category as a database, and never as a substitute for human creativity. On 14 July 2026 I
reverted the embedding layer in Making-A-LLM because an assistant had written it, and set a
rule for that project: it explains, I write.

I write decision records for everything I build, including the ones nobody else will read.
The reasoning outlives the code.
